# ventas/prospectos

Prospect lists used to choose which clinics and professionals to contact.

| File | What it is |
|---|---|
| `google_maps_2026-10-17.csv` | Scraped list of about 300 dental and aesthetic businesses in Bucaramanga and Medellin, with a score, category, city, rating and review count. Contact fields are fictional placeholders in this snapshot (names, phones, e-mails and links are generated). |
| `contadores_2026-10-21.md` | Prospect notes for the accountant niche. Contact data is not in this snapshot. |

Column meanings for the CSV: `puntaje` is a numeric score (its meaning is not documented in the file), `whatsapp` and `telefono` are the phone fields, `google_maps` is the listing link.
