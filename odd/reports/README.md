# odd/reports

Read-only reports produced for the hosted-services exit plan. They describe the hosting environment; they contain no credentials, variables or customer content.

| File | What it is |
|---|---|
| `railway-exit-inventory.md` | Inventory of the hosted projects, services, images and volumes, with capacity and usage per volume. Identifiers are redacted. |
| `railway-backup-readiness.md` | Readiness check for backups of the hosted data before any move. |

Connections: the matching feature document is `../tasks/railway-exit.md`.
