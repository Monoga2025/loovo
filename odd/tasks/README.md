# odd/tasks

Feature documents for work tracked with Organic Driven Development. Each file has a header (objective, branch, runner), numbered specs (`S1..Sn`) quoting the user's requirements, a task list, and a log.

| File | Feature |
|---|---|
| `railway-exit.md` | Preserve the hosted projects and their data before a possible exit from the host. Local backups and evidence only; no shutdown, deletion or migration. |
| `pi-voice.md` | Push-to-talk voice dictation for the Pi agent harness on Windows, with local transcription and no automatic submit. |

Connections: the evidence for `railway-exit.md` is in `../reports/`. Feature documents for the content work are in `../../Maquina de redes/odd/tasks/`.
