# landings

Lead-capture landing pages, one folder per niche (for example `contadores/`). Visitors arrive from the content funnel and leave a WhatsApp contact; the lead data is then sent to the CRM in [omni-sales-crm](https://github.com/Monoga2025/omni-sales-crm), never stored here.

## What is in this repository

Only the rules (`AGENTS.md`, `CLAUDE.md`). The page sources themselves are not present in this snapshot, so this folder currently documents the process rather than shipping a site.

## Process

1. Generate the visual asset.
2. Build the page with the `b2b-web-director` skill.
3. Review screenshots before publishing.

Rules: the page asks only for the minimum (a WhatsApp number) with a personal-data notice under Colombian Law 1581. No claim that a system works unless it is marked as working in `../SHARED_STATE.md`.
