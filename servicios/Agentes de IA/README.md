# Agentes de IA

n8n workflows that the content videos promise. The first set is for Colombian accountants, the niche of campaign "contadores 01": three flows, labelled D1, D2 and D3.

## What is in here

| Folder | What it is |
|---|---|
| `contadores-d1-d2-d3/` | The three n8n workflow JSON files, their scripts, fictional test data and the scout report. See its README. |

## Status

🟡 The workflow JSON files are drafts adapted from public templates. They have **not been imported into n8n or run end to end**. The JavaScript inside the Code nodes is tested with Node on fictional data.
