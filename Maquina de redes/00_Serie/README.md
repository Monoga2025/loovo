# 00_Serie

The series bible for "Loovo-42". Every day's script and caption checks against this folder before publishing.

| File or folder | Purpose |
|---|---|
| `hechos.md` | Facts allowed on air. Each line is marked as done, partial or coming soon. Only "done" facts can be stated as fact. |
| `voz-y-estilo.md` | Voice and style, built from the founder's real quotes; updated every day. |
| `marcador.md` | Scoreboard: one row per day with date, topic, status and results. |
| `aprendizajes.md`, `banco-frases.md` | Lessons learned and a bank of phrases. |
| `estado.md`, `relevo.md` | Current state of the series and a handoff note between sessions. |
| `videos-5-repos.md`, `videos-repos-01-hyperframes.md` | Notes on reference repositories and video tooling. |
| `guiones/` | Scripts, including per-day packages and research material. |
| `marca/`, `portadas/` | Brand assets and cover designs. |
| `proxima-LP/` | Notes for the next landing page. |
| `recursos/` | Reference resources (fonts, sounds, images). |

Connections: scripts are written in `guiones/` and must follow `voz-y-estilo.md`; covers and captions use the rules in `../instagram/`.
