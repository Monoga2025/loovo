# guiones

Rules for writing scripts. The folder holds the instructions (`AGENTS.md`, `CLAUDE.md`); the script files themselves live in `../00_Serie/guiones/` and in each day folder.

## Two formats

| Format | Use |
|---|---|
| Niche videos that must convert (for example accountants) | A short sales script with a clear call to action. |
| The "Day X of 42" series | Daily story script that checks every claim against `../00_Serie/hechos.md`. |

Before writing, read `../00_Serie/hechos.md` and `../00_Serie/voz-y-estilo.md`. Scripts are written by the most capable model, as set in the model table of the root `AGENTS.md`.
